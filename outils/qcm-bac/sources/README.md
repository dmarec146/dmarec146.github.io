# Sources du bloc « QCM Bac » (Terminale spécialité)

Documents officiels sur lesquels s'appuient les banques de questions. **Ce dossier fait partie du dépôt** : une session
Claude Code (cloud ou sur n'importe quel PC) les retrouve après `git fetch`. Sur `master`, ils seraient servis par
GitHub Pages comme le reste du dépôt ; ce sont des documents publics et aucune page du site n'y renvoie.

| Fichier | Contenu | Origine |
|---|---|---|
| `programme-terminale-specialite-maths.pdf` | Programme de spécialité de mathématiques de la classe terminale générale (annexe du Bulletin officiel : contenus, capacités attendues, démonstrations, approfondissements possibles, exemples d'algorithmes), 21 pages | Ministère de l'Éducation nationale et de la Jeunesse, document déposé par David le 17/10/2026 |
| `programme-terminale-specialite-maths.txt` | Même document en texte (extraction automatique, formules parfois abîmées) : plus rapide à parcourir qu'un PDF ; en cas de doute sur une formule, le PDF fait foi | extrait du PDF le 18/10/2026 |

Le découpage du programme en thèmes de banques (suites, géométrie dans l'espace, etc.) est dans
`../pilote-suites.md` §1.

## Ajouter un document

- Un fichier par document, nom en minuscules avec des tirets (`sujet-metropole-2026-j1.pdf`).
- Une ligne dans le tableau ci-dessus : contenu, origine, date.
- Pour les sujets de bac, ne garder que **les exercices retenus** (énoncé, corrigé officiel, référence : année, centre,
  numéro, lien), pas les sujets entiers : voir `../index-exercices.md`. Les fichiers `.tex` de l'APMEP se retéléchargent
  depuis les adresses notées dans `../SUIVI-QCM-BAC.md` (§2).
